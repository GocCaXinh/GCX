## 🚀 Web Development

The official website is built using **Next.js + Tailwind CSS + TypeScript**.

### Getting Started

1. Install pnpm
   ```bash
   npm install -g pnpm

   ```

2. Install dependencies

   ```bash
   pnpm install
   ```

3. Run the development server

   ```bash
   pnpm dev
   ```

4. Configure the contract address in

   ```
   src/constant/contract.ts
   ```
